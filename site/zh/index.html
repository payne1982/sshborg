// 系统功能

💻

完整 SSH 终端

支持 VT100/xterm 仿真、完整 UTF-8 和多个并发会话的交互式终端。

📁

SFTP 文件管理器

通过直观的文件管理器浏览、上传、下载、重命名和删除服务器文件。

🔑

SSH 密钥认证

直接在设备上生成 Ed25519、ECDSA 和 RSA 密钥，无需密码。

🔌

跳板机支持

通过一台或多台堡垒主机进行透明隧道连接，完整支持 SSH 代理转发。

🔒

生物识别锁

通过指纹或人脸解锁保护服务器访问权限，超时时间可自定义。

🌐

多语言

支持英语、意大利语、法语、德语、西班牙语、葡萄牙语、乌克兰语、中文和日语。

🌓

深色与浅色主题

跟随系统主题，或手动选择。在任何光线条件下均清晰可读。

⚡

多会话

同时保持多个 SSH 和 SFTP 会话，即时切换。

⚙⚙⚙
