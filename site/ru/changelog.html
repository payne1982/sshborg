История версий

Все выпущенные версии, начиная с последней.

⚙⚙⚙
Android iOS

1.17.12026-09-19

  • SFTP: исправлены загрузки, которые могли обрывать соединение или давать ошибку
  • SFTP: ошибки остаются на экране и копируются; неудачные файлы пропускаются и выводятся списком
  • SFTP: загрузка спрашивает, прежде чем заменить существующий файл
  • SFTP: список сохраняет позицию после удаления, загрузки и скачивания
  • Блокировка: время считается с выхода из приложения; выбор файла не требует разблокировки
  • Терминал: история команд читается без повторного входа

1.17.02026-09-15

  • Теперь список хостов и групп можно упорядочить (по алфавиту, недавние, часто используемые или вручную)
  • Исправлена прокрутка в полноэкранных программах, таких как tmux, vim, nano и less
  • Исправлены клавиши на панели, которые могли продолжать повторяться после отпускания
  • Режим слов теперь приостанавливает подсказки команд
  • Исправлены подключения через промежуточный хост, которые могли бесконечно загружаться
  • Android TV: выбранную клавишу или кнопку теперь хорошо видно

1.16.22026-09-10

  • Android TV: баннер и значок полного размера на главном экране

1.16.02026-09-09

  • Настраиваемая панель дополнительных клавиш: выберите раскладку (один ряд, два ряда, минимальная) или создайте свою с любыми клавишами, текстовыми макросами и до трёх рядов — переключение с панели через ⇄
  • Удобнее навигация D-pad на Android TV: текстовые поля и списки легко использовать с пульта
  • Исправлен экран блокировки на горизонтальных ТВ, где нижний ряд мог обрезаться
  • Панель выделения: «Копировать всё» в конце и приглушено, чтобы не нажимать вместо «Копировать выделенное»

1.15.12026-08-31

  • Исправлено: переименование SSH-ключа теперь обновляет и комментарий внутри открытого ключа
  • Обновлённый значок приложения, заполняющий рамку, в том числе на Android TV

1.15.02026-08-23

  • Поддержка Android TV: установка и навигация с пульта — для ввода рекомендуется физическая клавиатура (USB или Bluetooth)
  • Более удобный ввод текста с клавиатурой на несенсорных устройствах, таких как Android TV
  • Исправлен вход по паролю на серверах, предлагающих только аутентификацию keyboard-interactive
  • SFTP: новая опция показывать папки перед файлами

1.14.02026-08-19

  • Дублируйте хост из его меню, чтобы повторно использовать настройки для нового подключения — удобно для того же сервера на другом порту или через другой промежуточный узел
  • Показывайте или скрывайте скрытые файлы (dotfiles) в браузере SFTP — сохраняется для каждого хоста
  • Новая блокировка приложения: защитите его встроенным PIN или парольной фразой
  • Библиотеки и инструменты сборки приложения обновлены до последних стабильных версий

1.13.12026-08-12

  • Переработаны экраны ошибок и отключения: понятная сводка и разворачиваемые детали, которые можно прокрутить и скопировать
  • Более стабильные соединения: держит Wi-Fi активным во время сессий и чаще проверяет связь
  • Исправлен редкий сбой, и теперь приложение уведомляет, когда ограничение времени Android в фоне останавливает сессии

1.13.02026-08-08

  • Переключайтесь между сессиями на разных хостах прямо из панели вкладок терминала
  • Нажмите на имя загруженного файла, чтобы открыть его, — с экрана загрузки или панели передач
  • Улучшено отображение эмодзи и широких символов (CJK) в терминале
  • Исправлен обрезанный текст в начале первой сессии терминала
  • Исправлены фоновые сессии, которые могли перестать принимать ввод
  • Панель дополнительных клавиш видима без клавиатуры

1.12.12026-08-05

  • Улучшено выделение текста у краёв терминала
  • Исправлен серый экран, который иногда мог зависать
  • Улучшена навигация SFTP для предотвращения обрывов соединения
  • Нажмите на уведомление о загрузке, чтобы открыть файл и увидеть путь сохранения

1.12.02026-08-02

  • Новые варианты блокировки: биометрия, PIN/ключ устройства или без — удобно на Android TV
  • Терминал показывает глифы Nerd Font / Powerline (напр., приглашения Starship)
  • Резервные копии запоминают ключ каждого хоста по имени
  • Добавлена вставка в меню выделения терминала
  • Стрелки и PgUp/PgDn на панели клавиш теперь повторяются при удержании

1.11.12026-07-29

  • Исправлен отсутствующий шрифт интерфейса
  • Исправлены подсказки команд, которые не появлялись после переключения вкладок сессий

1.11.02026-07-26

  • Приложение теперь доступно на русском языке благодаря переводу от сообщества
  • Исправлена утечка памяти при выходе из сессии терминала
  • Более плавная и отзывчивая прокрутка терминала
  • Терминал возвращается вниз при вводе текста
  • Двойное касание для отправки Tab при желании (автодополнение)
  • Резервные копии теперь включают настройки приложения
  • Новая опция для сброса принятого ключа хоста

1.10.02026-07-23

  • Hosts can now be organized into collapsible color-coded groups, with custom per-host colors too
  • New light terminal color scheme (black on white), also able to follow the app theme
  • New setting to keep the screen on while a terminal is open
  • Physical keyboard: Ctrl and Alt key combinations now work in the terminal
  • Fixed a crash when generating SSH keys on Android 12 and older, plus minor fixes

1.9.02026-07-18

  • SFTP: fixed several issues when cancelling downloads
  • Terminal: selection handles are easier to drag, and copied text no longer contains fake line breaks where long lines wrap
  • New setting: default terminal font size
  • App lock: unlock is now biometric-only (PIN/pattern only if no biometrics are enrolled)
  • Updated internal libraries

1.8.02026-06-20

  • SSH agent forwarding: fixed a message-framing bug that could break sessions with recent OpenSSH servers (jsch 2.28.3)
  • Hosts list: the last host is no longer hidden behind the add button when the list fills the screen
  • Downloads: show start and finish date/time; foreground downloads end on a completion screen with a Done button
  • Session tabs: new browser-style tab bar, and the keyboard stays open when you switch tabs

1.7.02026-06-09

  • SFTP: background downloads — download files without blocking the file browser; long-press a file for the "Download in background" option
  • SFTP: active downloads can be sent to background at any time using the "Background" button
  • Host settings: "Allow Legacy Ciphers" option for connecting to old servers that only support outdated algorithms (AES-CBC, 3DES, DH-group1/14-sha1, DSA)
  • Terminal: improved spell-check (word) mode
  • Minor bug fixes and improvements

1.6.12026-05-19

  • SFTP: fixed a hang when connecting via jump host on mobile networks — the connection now times out and shows an error instead of spinning indefinitely
  • Terminal: word mode — tapping a spell correction suggestion now correctly replaces the mistyped word (Android 13+)
  • Minor bug fixes and improvements

1.62026-05-17

  • Terminal: fixed "connection lost" message appearing after a normal exit (exit/logout command)
  • Updated JSch SSH library to version 2.28.2, which includes a fix for agent forwarding when the client sends an extension message (SSH2_AGENTC_EXTENSION)
