SSHBorg

Un potente client SSH & SFTP per Android.
Gestisci i tuoi server in sicurezza, direttamente dal telefono.

✓ Senza pubblicità ✓ Senza tracciamento ✓ Senza cloud Gratuito Android 10+
Scarica su Google Play Esplora su AppGallery
⚙⚙⚙

// FUNZIONALITÀ

💻

TERMINALE SSH COMPLETO

Terminale interattivo con emulazione VT100/xterm, supporto UTF-8 completo e sessioni multiple simultanee.

📁

FILE MANAGER SFTP

Naviga, carica, scarica, rinomina ed elimina file sui tuoi server con un file manager intuitivo.

🔑

AUTENTICAZIONE A CHIAVE

Genera chiavi Ed25519, ECDSA e RSA direttamente sul tuo dispositivo. Nessuna password necessaria.

🔌

JUMP HOST

Connettiti attraverso uno o più bastion host con tunnelling trasparente. Forwarding completo dell'agente SSH.

🔒

BLOCCO BIOMETRICO

Proteggi l'accesso ai tuoi server con impronta digitale o riconoscimento facciale. Timeout configurabile.

🌐

MULTILINGUA

Disponibile in inglese, italiano, francese, tedesco, spagnolo, portoghese, ucraino, cinese e giapponese.

🌓

TEMA SCURO E CHIARO

Segue il tema di sistema o ti lascia scegliere. Perfettamente leggibile in qualsiasi condizione di luce.

⚡

SESSIONI MULTIPLE

Tieni aperte più sessioni SSH e SFTP contemporaneamente. Passa da una all'altra istantaneamente.

⚙⚙⚙
