• SFTP: editor integrato per i file sul server — i file di testo si modificano sul posto e mantengono codifica, fine riga e permessi, i file di configurazione vengono colorati, e ciò che non è testo si apre in un editor esadecimale
• Chiavi SSH: una chiave con passphrase ora funziona — la passphrase viene chiesta una volta sola all'importazione e non viene salvata da nessuna parte. Le chiavi importate prima vanno reimportate; la lista le segnala.
